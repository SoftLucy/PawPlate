# Cost model (placeholder)

Target: investigate whether a reproducible two-zone built-in induction hob could approach a €100 retail price at production scale. This is an aspiration, not a current cost estimate.

Track separately:

- Power semiconductors, magnetics, resonant capacitors, sensing and control
- Induction coils and ferrites
- Glass ceramic, enclosure, insulation, cooling and user interface
- PCB fabrication, assembly, wiring and fasteners
- Testing, certification/compliance, packaging, logistics, warranty and taxes
- Manufacturing volume assumptions, yield, margin and distribution

Do not compare raw component cost directly with retail price. Populate figures only with dated, sourced prices and explicit quantities.

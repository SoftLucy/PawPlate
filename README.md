# PawPlate 🐾

An open-source, repairable two-zone built-in induction cooktop, inspired by affordable domino hobs.

## Project status

**Concept and research only.** No hardware has been built or validated. Mains-powered induction circuitry can be lethal; designs must undergo appropriate engineering review and safety testing before physical use.

## Goals

- Target a compact, two-zone built-in hob comparable to a budget 3.4 kW domino cooktop.
- Publish reproducible hardware, firmware, mechanical design, documentation, and cost estimates.
- Prioritize repairability, documented interfaces, and readily available components.
- Explore power-sharing architectures and cost reduction through research and simulation before hardware spending.
- Keep the initial project achievable with a zero-budget, documentation-first workflow.

## Safety and maturity

This repository is not a construction guide for a working mains-powered appliance. Any future power-electronics design will require qualified review, appropriate test equipment, and validation against applicable appliance and electrical-safety requirements. Simulation and documentation do not establish safety.
